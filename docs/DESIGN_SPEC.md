> 本文件是唯一事实来源。任何规则变更必须同步更新本文件对应章节，并在 docs/CURRENT_STATE.md 第五节的"最近决策变更"表格中留一行。
> 使用说明：本文档是「轨迹」App 的唯一设计事实来源。执行前先读本文档。参考图在 refs/ 目录，只参考本文档标注的内容，不参考未标注的部分。与 PROJECT_BRIEF.md 冲突时，技术约束以 BRIEF 为准，视觉/交互以本文档为准。

## 0. 项目背景
- **项目名**：轨迹（产品视觉与交互用名。注：在 PROJECT_BRIEF.md 中，项目定义为“语音旅行记账 PWA”）。
- **一句话**：一个纯本地、无后端的语音旅行记账 PWA。可分发、可离线、数据不出设备。

## 1. 项目第一原则（最高优先级）
系统只做引导和联想。用户提交什么，就按什么处理——认为他提交的就是对的，不做替他判断、替他更改的行为。

推论：
- 解析只做"预填草稿"，不做"纠错"。
- 地点、分类按用户输入的原文精确处理，不归一化。
- 用户输入什么就存什么，不猜、不改。

| 层 | 字体 | 用在哪 | 颜色 |

禁止：从 CDN 加载字体、引外部 web font。

### 2.3 手绘质感方案（替代旧 SVG 抖动方案）
- 文字：不抖。手写感靠字体本身。
- 线条（按钮框、输入框框、简笔图形）：SVG 内联 + stroke-dasharray 断续 + feTurbulence baseFrequency=0.9 numOctaves=1 + feDisplacementMap scale 1.5～3。
- 色块（按钮底色）：用 SVG rect + filter 做抖边，不用纯 CSS 圆角。
- 装饰图片（印章、卡片边框）：PNG 素材，来自生图 AI 或 Keynote 导出。
- 硬规则：任何随滚动重绘的元素不加 filter。

### 2.4 按钮
- 底色 #b0483a
- 文字：思印宋（SiyinSong），字号按换算表（首页主按钮 16px，其他页面按 Keynote 坐标 ×0.3611 换算）
- 边缘毛边：SVG rect + filter（scale 1.5～3），填充与描边同色 #b0483a，stroke-width 2
- 圆角 6px（SVG rect rx=6）
- 右侧小圆点：按各页面设计稿决定，首页无
- 不使用旧「强抖滤镜」，不用纯 CSS 圆角

### 2.5 印章（每页一枚，首页无）
- 正方形 44×44（不是圆角矩形）
- 红棕底 #b0483a，白字
- 抖动强度大于按钮
- 位置：页面标题左侧

### 2.6 卡片
两种方案可选：
- 普通卡片：border-image 引用 ../assets/card-frame.png，中心透明，slice=50，width=20px，fill 关键字。
- 特殊卡片（车票）：SVG 手绘虚线边框 + 半透明底。

> 票根类框（游笺卡片 / 驿站合计框）统一用朱砂红 #b0483a 手绘虚线边框，无填充底色；底色如需淡色，用极浅的灰白透明 rgba(255,255,255,0.35)。

### 2.7 列表条目

## 3. 交互规格
### 3.1 五层结构
首页（一笔载岁 静记流年）
  ├─ 中间输入框（打字/语音）→ 提交 → 载录
  └─ 底部 tab：账 | 记 | 户

载录（印：记 · 简笔：毛笔）「初启其端，落笔由你」
  钱 / 分类 / 时间 / 地点 / 备注 → 缮录归帙 → **跳转账簿页**

账簿（印：账 · 简笔：账本）← 点"账"
  ├─ [查] → 查页面（印：查 · 简笔：眼镜）→ 筛选结果列表
  │         （可导出；纯时间筛选时可存为旅程）
  ├─ [清] → 清空后显示「辞却前尘 重启征程」+ [重启] 按钮跳回首页
  └─ 全列表（按日期倒序，每条可编辑/删除）

户 ← 点"户"（游笺 · 印：藏 · 简笔：信封）「辑藏履痕，存此片忆」
    └─ 一段旅程 → 轨迹（印：迹 · 简笔：纸飞机/车马）
                   ├─ 车票快照
                   ├─ 轨迹图（页面最大元素）→ 点某点 → 驿站
                   └─ 花费分类汇总
                   （轨迹、驿站均带 [详] 按钮，进明细列表）

驿站（印：算 · 简笔：算盘）
  某时间段 + 某地点花费汇总（条状图）+ [详] 按钮进明细

### 3.2 首页
- 顶部标题区（"一笔载岁，静记流年"）
- 中间大输入框（打字/语音），最显眼元素
- 提交按钮"谨存此笔"
- 底部小灰字"日子翻过去，手账留下来。"
- 底部装饰（纸飞机带尾线 + 波浪线）
- 三 tab：账｜记｜户
- 无印章
- 首页是「记」tab 的默认页。三 tab 结构：账（账簿）/ 记（首页）/ 户（游笺）。

### 3.3 载录（草稿模式）
- 首页提交 → 进表单页
- 五项：钱 / 分类 / 时间 / 地点 / 备注
- 解析预填只做一次；用户改任何字段后，改备注不再重算
- 顶部印章"记" + 毛笔简笔
- 文案："初启其端，落笔由你"
- 保存按钮："缮录归帙"
- **保存后跳转账簿页**（2026-09-26 S4-B 拍板）
- 载录页是模态页，无底部 tab。
- 左上角（「金额」标签同行）有朱砂色 ← 返回入口；点击返回首页，若已有输入内容弹确认框（弹窗系统统一做时落地，见 BACKLOG B-60）。

> **2026-09-20 补充**：载录页保存时强制校验四字段非空（金额/时间/地点/备注，空格视为已填）。预填规则：金额/日期/分类从 rawText 解析（复用 parser.js），日期无则今天、分类无则其他；地点解析（新功能）无则"在途"；备注预填 rawText。rawText 只做预填用途，保存后废弃。（实装属 S4-B）。

### 3.3.1 分类枚举（一级分类，6 项）
餐饮 / 交通 / 自驾 / 住宿 / 门票 / 其他

说明：
- 「交通」= 飞机、高铁、火车、大巴、打车、地铁、租车
- 「自驾」= 加油、充电、过路费、停车费
- 加油/过路费的具体拆分写进备注
- 一级分类保持互斥、无重叠，不做二级科目
- 图标 3×2 布局，自驾用方向盘

### 3.4 账簿页
- 全列表，按日期倒序（最新在上）
- 顶部：印章"账" + 账本简笔 + 两个按钮 [查] [清]
- 查/清按钮的红色状态表示当前激活的操作。列表态默认"查"为红（进入筛选视角），点击"清"后切换为"清"为红。空状态下两按钮可隐藏或变灰。
- 每条支持编辑/删除（⋯ 操作）
- 清空后显示："辞却前尘 重启征程" + [重启] 按钮，点击跳回首页

### 3.5 筛选（[查] 按钮）
- 账簿 [查] → 阅踪页（模态页，无 tab）。
- 阅踪页结构：顶部制式（印章「踪」+ 页题「阅踪」+ 对仗「罗陈途记 遍览游踪」+ 卷号 + ← 返回）；筛选条（起始日期 / 结束日期 / 地点 / [寻踪]）；操作行（[归档] / [存卷]）；列表（按日期分组，每笔两行）；合计条（贴底）。
- 筛选交互：日期用原生 input date（max=今天，2026-09-20 改）；地点用 text + datalist（精确匹配）；[寻踪] 显式触发。
- [存卷] 规则（2026-09-20 修订）：存卷按钮置灰条件：① 带地点筛选 ② 结果为空 ③ 筛选输入框被改动但未重新点[寻踪]（防"改了条件却存旧结果"的困惑）。

**筛选条补充（2026-09-20）**：
- 三个输入（起始日期 / 结束日期 / 地点）**均可空**。空条件不参与过滤。
- 日期两端都空 → 只按地点过滤；只填一端 → 开区间；全空 → 显示引导空态。
- 日期 input 加 `max="今天"`（用户选不到未来）。
- 起 > 止 → toast 报错，不查询。
- openTrace 进页不预填日期（用户从头填，避免视觉与 value 不一致）
- 全空（三个输入都空）→ 显示引导空态，不查询
- applyTraceFilter 开头强制失焦（Safari date 提交怪癖防御）

### 3.6 游笺
- 旅程列表，每条支持删除
- 印章"藏" + 信封简笔
- 文案："辑藏履痕，存此片忆"

### 3.7 轨迹
- 顶部：车票（快照：名字 + 起止日期）
- 轨迹图（纵向蜿蜒虚线 + 彩点 + 简笔地标 + 局部晕染）—— 页面最大元素
- 花费汇总（总花费 + 日均 + 分类饼图/条状图）
- "查看每日明细 →" 链接（跳账簿页 + 预填时间段）
- 点轨迹点 → 进驿站
- 印章"迹" + 纸飞机/车马简笔

### 3.8 驿站
- 某段时间 + 某个地点的花费汇总（条状图）
- "详"按钮 → 详细列表
- 印章"算" + 算盘简笔

### 3.9 统一明细页
**统一明细页 = 阅踪**

五个入口共用同一页面，只是筛选条件预填不同：
- 账簿 [查] → 空筛选（用户自填）
- 游笺行程 [详] → 预填行程起止日期
- 驿站 [详] → 预填起止日期 + 地点
- 账簿点某天 → 预填该日期（S3-09）
- 行程明细（旅程快照）→ 预填行程起止日期

支持导出筛选结果。**S3-08 落地**。

### 3.10 旅程规则
- 旅程 = 自动快照，不命名。字段：{ id, ownerId, fromYmd, toYmd, startLoc, endLoc, createdAt }
- 起点 = 最早日期那天的 location（空 → "在途"）；终点 = 最晚日期那天的 location（空 → "在途"）。不往前找。
- 单笔数据 → 只显示单个地名
- 地点按精确字符串分组，不做归一化（matchLocation 依据）
- 旅程是视图不是副本：删旅程不动账目；改账目旅程自动变

### 5.1 错落文案字号规则
小文案（如「初启其端 落笔由你」）用思印宋，每字大小不同，形成错落感。
载录页实测：初17 / 启21 / 其16 / 端19 / 落21 / 笔17 / 由16 / 你19（px）
规则：重音字（启、落）加大到 21，其余在 16-19 之间变化，避免均匀。
未来同类文案（如「辞却前尘 重启征程」）参照此规则。

## 6. 禁令清单（违反即视为失败）
